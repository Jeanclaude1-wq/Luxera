# Luxera – Hotel Booking Platform

## Project Overview

Luxera is a hotel booking platform developed as a university graduation project for the Bachelor of Computer Science program at Arab Open University.

The platform is designed to simplify the hotel booking process by allowing users to explore hotels, view available rooms, and manage reservations through a user-friendly interface.

It also provides management features for hotel owners and administrators to manage hotel information, rooms, bookings, and users.

## Features

- **Hotel Browsing:** Explore hotels and view their details.
- **Room Management:** Manage hotel rooms, prices, and availability.
- **Booking Management:** Create and manage hotel reservations.
- **User Accounts:** Registration, login, and user profile management.
- **Hotel Owner Dashboard:** Manage hotel information, rooms, and reservations.
- **Admin Dashboard:** Manage users, hotels, and platform activities.
- **Customer Support:** Support functionality for assisting users.

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- MySQL

## Project Structure

The project is organized into Django applications, templates, static files, and database components.
